CodexManagerLocal macOS first launch

This local build is not notarized. If macOS blocks the first launch:

1. Double-click "Open CodexManagerLocal.command" in this folder.
2. Confirm the Terminal prompt if macOS asks for permission.
3. If needed, open System Settings > Privacy & Security and allow CodexManagerLocal.

The helper removes the quarantine flag only for the local app bundle in this
folder or in /Applications.
