# IP 人员绑定

桌面 App 的“系统设置 → 通用 → IP 人员绑定”支持导入 `.xlsx` 人员表。

1. 点击“导入人员表”，选择文件。读取第一个工作表中的“姓名”和“IPv4 地址(IP)”或“IP”列，允许表头前存在标题行。
2. 核对预览中的姓名、IP、有效数量和跳过数量，点击“确认替换”并确认。
3. 仪表盘实时请求、IP 分组、请求日志，以及平台密钥中的“内网 IP 用量”立即按当前绑定显示 `IP（姓名）`。未匹配显示 `IP（未绑定）`，缺少客户端 IP 的请求保留原有未知标记。

导入会替换整份映射，不追加；“清空绑定”需要单独确认。历史日志按当前映射显示，不记录或推断过去的实际使用人。共享 IP、代理或地址重新分配可能导致姓名与实际操作者不一致，绑定仅是显示备注，不能用于身份认证。

## 数据规则

- 文件不超过 2 MiB，最多 5000 个绑定，姓名为 1–100 个字符。
- 空白行忽略，缺少姓名或 IP 的行跳过。首尾空格及 IPv4 点号旁的格式空格会清理，原始 Excel 文件不修改。
- 无效 IP、同一个 IP 对应不同姓名时整次导入拒绝，保留原有映射。相同 IP 与姓名的重复行合并。
- 支持 IPv4、IPv6 以及 IPv4-mapped IPv6 的统一匹配。界面保留原始请求 IP，文字单行完整显示，超宽时横向滚动。
- 校验或保存失败时不主动清空旧绑定；导入不会改变任何请求放行、账号分配、IP 并发、Token 或费用统计规则。

## 隐私

映射使用桌面默认 SQLite 数据库中的 `app.client_ip_names` 设置保存，默认空映射。不得将人员表或真实姓名/IP 映射写入源代码、测试夹具、安装包或 GitHub；安装到另一台电脑后需在那里导入人员表。

设置接口对普通成员隐藏人员映射，修改仅允许管理员。启用非默认 SeaORM 存储模式时不接受人员映射写入，以避免将此本地通讯录发送到远程数据库。
